# HearthLedger — Household Cashflow & Budget Planner

Offline-first household budget application with envelope tracking, 50/30/20 rule allocator, transaction ledger, sinking funds, debt payoff simulator, and recurring bill schedule.

## Run Locally

```bash
node serve.ts --port 8081
```

## Build Submission Output

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```
